## Display decisions

- Existing 48px card and 64px detail slots are retained. `ToolLogo` uses contain
  sizing, with no clipping, border radius, filters, shadows or color overrides on
  marks. Card backgrounds, spacing and decorative treatments stay unchanged.
- VS Code: blue stable icon; 1/6-slot padding leaves clear space equal to 25% of
  the rendered icon width. This is an illustration within educational content,
  separate from the normal page heading, not a newly composed brand lockup.
- GitHub: current black Invertocat with supplied clear space, beside an explicit
  GitHub heading. Used as secondary identification in educational product content,
  consistent with the Toolkit's listed editorial uses; not DevJourney branding.
- Figma: supplied full-color icon including its original generous blank canvas.
  A white image background complies with the brand book. Canvas plus surrounding
  card/header spacing separates the visible mark from text by at least its height.
  The complete non-square canvas is contained, never cropped or stretched.
- Netlify: the official encapsulated light-mode variant is intended for directory
  contexts alongside other tools; no deployment badge or claim of completed hosting.
- All images are decorative beside visible product headings and render with
  `alt=""`. Descriptive asset metadata remains in the data for other contexts.

## Unresolved OpenAI visual issue — human review

[OpenAI's brand guidance](https://openai.com/brand/) was read. It requires supplied,
unaltered marks, appropriate spacing and use within its permission terms. The
public page could be read through web retrieval, but direct retrieval returned
403 and [the full brand portal](https://brand.openai.com/) redirected to sign-in.
A reliably obtainable, product-appropriate ChatGPT/Codex download and its applicable
usage could not be verified in this session. No favicon was substituted, and no
separate Codex logo was invented. Both slots use the generic `neutral-tool.svg`.
An official replacement remains a human-review item, not a claim that logo use is
forbidden. Obtain and verify the approved original before replacing this fallback.
